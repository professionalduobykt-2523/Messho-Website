# 🛍️ Meesho Clone

A responsive **Meesho Clone** landing page built using **HTML5** and **CSS3**. This project recreates the modern user interface of the Meesho website, focusing on clean design, responsive layouts, and an attractive shopping experience.

---

## 📌 Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and clean user interface
- Navigation bar with categories
- Hero/Banner section
- Product categories section
- Featured products display
- Promotional banners
- Footer with useful links
- Smooth hover effects and transitions

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

---

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/meesho-clone.git
```

2. Open the project folder.

3. Run the project by opening **index.html** in your browser.
